# ilmioinvito.com

Piattaforma per creare, pagare, pubblicare e gestire inviti digitali personalizzati.

## MVP

- Homepage prodotto
- Builder invito
- Anteprima invito pubblica
- Dashboard cliente con partecipanti e impostazioni
- Base schema Supabase
- Deploy previsto su Vercel

## Comandi

```bash
npm install
npm run dev
npm run build
```

## Variabili ambiente previste

```bash
NEXT_PUBLIC_SITE_URL=https://ilmioinvito.com
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
STRIPE_SECRET_KEY=
STRIPE_WEBHOOK_SECRET=
```
